# Geekie Study Hub — v19.2.0

Um hub de estudos em português com portal integrado, Tutor IA, Pomodoro, notas, metas, flashcards, temas, estatísticas e ferramentas de apoio. O projeto é distribuído em três arquivos: HTML para a estrutura, CSS para o visual e JavaScript para o comportamento.

## Como abrir

Mantenha os três arquivos abaixo na mesma pasta e abra o arquivo HTML em um navegador atualizado:

- `attached_assets/index_-_2026-10-22T121140.950_1792767105936.html`
- `attached_assets/style_(13)_1792767105930.css`
- `attached_assets/script_(19)_1792767105934.js`

O HTML já aponta para os nomes exatos dos arquivos CSS e JavaScript deste pacote. Font Awesome e as fontes tipográficas são carregados de serviços externos; alguns portais integrados também dependem de conexão com a internet e de permissões do navegador.

## Novidades desta edição

- Controle global para alternar entre animações completas e movimento reduzido, com preferência salva neste navegador e respeito à configuração do sistema na primeira visita.
- Ripple em todos os botões, inclusive os criados dinamicamente; ativação por teclado também recebe feedback.
- Dev Log reorganizado com destaque da versão atual, contador de resultados, pesquisa, expandir/recolher e limpeza rápida da busca.
