# Geekie One Ultra

Hub de estudos em português, preparado para GitHub Pages. Mantenha `index.html`, `style.css` e `script.js` juntos na mesma pasta.

## Recursos

- Portal Geekie integrado, Tutor IA local, Google, notas, planner, metas, flashcards e Pomodoro.
- Gamificação com XP, moedas, temas, títulos, pets, eventos e trilha de progresso.
- Ferramentas de estudo: sons ambiente, calculadora, biblioteca de símbolos, quiz e estatísticas.
- Animações previsíveis e diferentes por categoria de botão, com preferência de movimento reduzido e foco visível.
- Cabeçalho reorganizado para celular; preferências e progresso permanecem salvos neste navegador.

## Publicar no GitHub Pages

Envie os quatro arquivos desta pasta para a raiz do repositório. No GitHub, abra **Settings → Pages**, escolha a publicação a partir da branch principal e da pasta `/ (root)`, e salve.

> A página usa serviços externos opcionais (fontes, ícones e conteúdo incorporado). O progresso do hub é armazenado no navegador e não é sincronizado entre dispositivos.
